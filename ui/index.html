Update firmware

  1. On the deck, open Settings and turn on Wi-Fi Remote.
  2. On this PC, join the deck's Wi-Fi network (Pajoniiir).
  3. Choose the signed update file (.ddjota). The deck checks the signature before it installs anything, and rolls back by itself if the new firmware doesn't start.
Wired recovery (USB)

For a first install, or a deck that won't start. Connect the deck's USB-C UART port. This overwrites the deck's firmware.
